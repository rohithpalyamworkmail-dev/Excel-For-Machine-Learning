# Excel for Machine Learning

## 📌 Project Overview

Excel for Machine Learning is a low-code, analytics-focused project that demonstrates how traditional business intelligence tools such as **Microsoft Excel**, **Power Query**, and **Power BI** can be effectively used in the **data preprocessing stage of machine learning workflows**.

The project focuses on transforming raw, messy data into clean, structured, and meaningful datasets suitable for machine learning models, without relying heavily on programming languages.

---

## 🎯 Problem Statement

Data preprocessing is the most complex and time-consuming phase of machine learning, often consuming up to 80% of project effort. Existing workflows rely heavily on programming libraries, creating barriers for non-programmers and shifting focus away from analytical thinking. This project addresses the gap by enabling efficient, visual, and low-code preprocessing using Excel, Power Query, and Power BI.

---

## 🚀 Objectives

- Reduce dependency on heavy coding during data preprocessing
- Enable visual and step-by-step data transformation pipelines
- Improve analytical focus over syntactical complexity
- Bridge the gap between business analytics and machine learning
- Accelerate time from raw data to model-ready data

---

## 🧠 Machine Learning Lifecycle Coverage

This project primarily focuses on the **early and most critical stages** of the ML lifecycle:

- Data Collection
- Data Cleaning and Validation
- Missing Value Handling
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Data Readiness for Modeling

> ⚠️ Model training and deployment are intentionally out of scope.
